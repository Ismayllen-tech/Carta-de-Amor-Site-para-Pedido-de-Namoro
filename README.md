# 💌 Carta de Amor — Site para Pedido de Namoro

Um site romântico de 3 páginas criado para fazer um pedido de namoro especial, com animações e visual elegante estilo carta vintage.

## 📄 Páginas

| Página | Arquivo | Descrição |
|--------|---------|-----------|
| 1 | `index.html` | Envelope animado — clique para abrir |
| 2 | `carta.html` | Carta de amor com texto romântico |
| 3 | `proposta.html` | Pedido de namoro interativo |

## ✨ Funcionalidades

- 🫶 **Envelope animado** — abre com animação suave ao ser clicado
- 📜 **Carta elegante** — papel pautado com efeito de caligrafia e selo de cera
- 💍 **Pedido interativo** — botão "Não" que foge do cursor 😄
- 🎉 **Celebração** — confetti e corações quando aceito
- 🌸 **Pétalas caindo** — animação de fundo em todas as páginas
- 🎨 **Design vintage romântico** — paleta quente, fontes elegantes

## 🚀 Como usar

1. Clone o repositório
2. Abra o `index.html` no navegador
3. **Não é necessário servidor** — funciona localmente com arquivos estáticos

```bash
git clone https://github.com/seu-usuario/carta-de-amor
cd carta-de-amor
# Abra index.html no navegador
```

## 🎨 Tecnologias

- HTML5 semântico
- CSS3 com animações puras (sem bibliotecas)
- JavaScript Vanilla
- Google Fonts: Playfair Display, Cormorant Garamond, Dancing Script

## 📁 Estrutura

```
carta-de-amor/
├── index.html       # Página do envelope
├── carta.html       # Página da carta
├── proposta.html    # Página do pedido
└── README.md
```

## 💡 Personalização

Para personalizar o texto da carta, edite o arquivo `carta.html` e altere o conteúdo dentro das tags `<div class="letter-body">`.

Para mudar o nome da assinatura, edite a `<span class="name">` no mesmo arquivo.
